Protect your account with phone verification

Two-step verification (2FA)

Add a phone number and verify it with a one-time SMS code. Once enrolled, VisionForge asks for a code after password or GitHub sign-in. Use a number you control and keep your recovery options current.

Checking your sign-in…

Include the country code, for example +91. SMS delivery requires the project's SMS provider to be configured in Supabase.

Phone verification is not enabled until the code is successfully verified.

Security notes

  • Phone SMS codes add a step, but authenticator-app passkeys or TOTP are generally stronger against SIM-swap attacks.
  • Never share one-time codes with anyone, including someone claiming to be support.
  • This prototype does not store phone numbers in a custom database table. Supabase Auth manages the factor.
  • Public-service documents should not be uploaded here unless the responsible organization has approved the system and its data handling.
