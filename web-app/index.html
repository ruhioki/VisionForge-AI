About this demo

This is the mobile-friendly browser companion to the Python/OpenCV VisionForge project. The edge filter uses a Sobel gradient approximation, not OpenCV's exact Canny algorithm. It is a portfolio demonstration, not a production diagnostic tool.

On Android, use your browser menu → Add to Home screen if offered.
